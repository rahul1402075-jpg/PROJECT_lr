Future Interest Analysis in Twitter Users Using Data Mining

A college Data Mining / Machine Learning mini-project.

Objective

Analyze a Twitter/X user's historical tweets to identify their current interests and predict likely future interests, using Natural Language Processing and Machine Learning classification, then present the findings through an interactive web dashboard.

Data Mining Pipeline Demonstrated

  1. Data Collection — CSV upload of historical tweets
  2. Data Cleaning & Preprocessing — lowercasing, URL/mention/emoji removal, stop-word removal
  3. Tokenization & Lemmatization — NLTK
  4. Feature Extraction — TF-IDF vectorization
  5. Classification — Logistic Regression, Naïve Bayes, SVM
  6. Model Evaluation & Selection — Accuracy, Precision, Recall, F1-score
  7. Pattern Identification — frequency & recency analysis per user
  8. Prediction — future interest & emerging interest detection
  9. Visualization — interactive Chart.js dashboards

Ethical & Responsible Use Notes

  • Predictions are based on available historical data and are probabilistic estimates, not guarantees.
  • The included dataset is synthetic sample/demo data, not real scraped Twitter/X data.
  • User privacy should be protected; avoid collecting sensitive personal information unnecessarily.
  • Any real API integration must follow Twitter/X's platform policies and applicable data-protection laws.
  • This system should not be used for harmful profiling or discriminatory decision-making.
